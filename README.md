# RENTTI

Landing del portal inmobiliario **RENTTI** (arriendo y compra en Chile).

## Stack

HTML + CSS + JS estático. Sin build step.

## Desarrollo

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Abre `http://127.0.0.1:8080`.

## Referencias de producto

Estructura inspirada en portales tipo TOC TOC / La Haus (búsqueda Compra/Arriendo, destacados, pasos).
Paleta propia: naranja coral, verde suave y grises claros (estilo Airbnb).

## Estructura

```
index.html
css/   tokens, base, hero, layout, motion
js/    search modes + reveal motion
assets/hero + listings
```
